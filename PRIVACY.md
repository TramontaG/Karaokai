# Privacy

KaraokAI is a local-first desktop application. It does not include telemetry,
advertising, analytics, user accounts, or a KaraokAI-operated cloud service.

## Data stored locally

The application stores the following data in the directory selected during
onboarding:

- projects, imported media, generated audio stems, subtitles, thumbnails, and
  exported-video working files;
- installed runtime components, machine-learning models, and their caches;
- application preferences, including language, theme, and default models;
- optional YouTube cookies supplied by the user.

The user can remove managed runtime data, models, and caches from Settings.
Projects and their media remain under the user's control in the selected data
directory.

## Network use

KaraokAI connects to third-party services only when requested by a feature:

- downloading the runtime, Python packages, and machine-learning models;
- importing a video from YouTube;
- checking or downloading dependencies requested by the user.

Those requests are made directly from the user's computer to the relevant
third-party provider. Their privacy policies and terms apply to those requests.

## User responsibilities

Do not add credentials, cookies, or media to a shared computer unless you are
comfortable with other users of that computer accessing the selected data
directory. You are responsible for removing optional YouTube cookies from
Settings when they are no longer needed.

## Changes

Changes to this document are published with the source code and application
releases.
